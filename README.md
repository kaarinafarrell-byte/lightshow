# Gym Light Show

Students scan a QR code and their phone screens flash in sync with the music.

| File | What it is |
|---|---|
| `index.html` | Student page. This is the link for the QR code. |
| `index.html#screen` | Big-screen view for the projector. |
| `setup-k7q2m9.html` | Teacher setup page (password protected). Don't share this link. |
| `shows.json` | Your shows and schedule. Replace this file whenever you change a show. |
| `engine.js`, `style.css` | Shared code. Upload once. |

Song files are never uploaded. Only beat timings go into `shows.json`.
